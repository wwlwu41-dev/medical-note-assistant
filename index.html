⚙️ Groq API 設定
🎉 Groq API 完全免費，不需要信用卡！
取得免費 Key（1 分鐘）
  1. 前往 console.groq.com（用 Google 帳號登入）
  2. 左側選單 → API Keys → Create API Key
  3. 複製 Key（格式：gsk_...）
🔒 Key 僅存於瀏覽器 localStorage，不外傳。
☁️ Firebase 雲端同步
輸入病歷號即可在電腦↔平板之間同步病人資料
免費設定步驟：console.firebase.google.com → 建立專案 → Firestore Database（測試模式）→ 專案設定 → 新增網頁應用程式 → 複製 apiKey 和 projectId
